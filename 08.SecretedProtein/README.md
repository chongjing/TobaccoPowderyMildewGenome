# Secreted Protein (Effector) Identification — *Golovinomyces cichoracearum* BFJ

Candidate effector proteins identified from the PASA-refined proteome of *G. cichoracearum* BFJ, using a two-step SignalP6 + DeepTMHMM pipeline.

## Pipeline overview

| Step | Tool | Input | Output | What it does |
|------|------|-------|--------|-------------|
| 1 | SignalP6 (fast, euk) | 11,677 predicted proteins | SignalP GFF/JSON | Predicts signal peptide (SP) probability for every protein |
| 2 | Filter by score > 0.8 | SP+-signal proteins | `03.SP.list` | Extracts 358 proteins with a signal peptide score > 0.8 |
| 3 | DeepTMHMM | 358 SP+ sequences | Topology predictions | Classifies each as SP (secreted), SP+TM, TM-only, or GLOB |
| 4 | Filter SP-only | Full SP+ + TMHMM types | `04.SP.secreted.list` | Keeps only SP+ proteins without a transmembrane domain → 289 secreted candidates |

## Results summary

| Category | Count |
|----------|-------|
| Total predicted proteins | 11,677 |

## How to reproduce

The `run_effectors.sh` script accepts environment variable overrides for all input paths. Defaults point to the original Dr. Xia project workspace.

```bash
cd 08.SecretedProtein

# Override input files if reproducing on another machine:
export PROTEIN_FA=/path/to/Golovinomyces_cichoracearum.proteins.fa
export SIGNALP6=/path/to/signalp6
export SIGNALP6_MODEL=/path/to/signalp-6-package/models
export DEEPTMHMM_PY=/path/to/python3
export DEEPTMHMM_SCRIPT=/path/to/DeepTMHMM/predict.py
export SEQKIT=/path/to/seqkit

bash scripts/run_effectors.sh 2>&1 | tee logs/effectors_rerun.log
```

The committed results/ files are the output of the original run and can be used directly without re-running the pipeline.

## Interpretation

For an obligate biotrophic powdery mildew with a compact genome (166.5 Mb, 11,677 protein-coding genes), 289 secreted candidates (2.5% of the proteome) is a biologically reasonable count. The signal peptide threshold of 0.8 is conservative (SignalP6 default recommends 0.5 for eukaryotes), which reduces false positives from signal peptide-like sequences in the compact G. cichoracearum genome.
